# Tartarum Primus - images

Illustrations from **Tartarum Primus**, an original tabletop RPG written and played by Riccardo De Bernardi. Every image here is **AI-generated** (ChatGPT) from the author's own prompts and curated by hand; the files are the Instagram-ready copies of the illustrations posted on the [Tartarum Primus](https://www.instagram.com/tartarum.primus/) account, and each one carries the IPTC `DigitalSourceType` field that declares it as AI-generated.

This repository exists only because the Instagram publishing API needs a public URL for each image. File names are neutral dates (`YYYY/MM/YYYY-MM-DD-NN.jpg`) on purpose.
